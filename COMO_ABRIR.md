# Cómo abrir tu curriculum web local

Esta carpeta funciona sin GitHub y sin Vercel.

## Opción 1: abrir directamente

1. Entra en esta carpeta:
   `C:\Users\hazae\Documents\Codex\2026-05-20\quiero-crear-una-p-gina-web\Curriculum_Web_Local`
2. Haz doble clic en:
   `index.html`

## Opción 2: abrir en Visual Studio Code

1. Abre Visual Studio Code.
2. Pulsa `Archivo > Abrir carpeta`.
3. Selecciona:
   `C:\Users\hazae\Documents\Codex\2026-05-20\quiero-crear-una-p-gina-web\Curriculum_Web_Local`
4. Para modificar:
   - `index.html`: textos, secciones y contenido.
   - `styles.css`: colores, tamaños, espacios y diseño.
   - `script.js`: menú móvil y modo claro/oscuro automático.

## Qué archivos importantes hay

- `index.html`: estructura de la web.
- `styles.css`: estilos separados.
- `script.js`: comportamiento simple.
- `assets/hazael-torres.jpeg`: tu foto.
- `assets/Hazael_Torres_CV.pdf`: tu CV descargable.

## Contadores

La web tiene dos contadores visibles:

- Descargas del CV.
- Clics en LinkedIn.

Estos contadores se guardan en el navegador con `localStorage`. En local sirven para probar y revisar la interacción. Si más adelante quieres contadores reales para una web publicada, habría que conectarlos a un servicio externo o a una pequeña base de datos.

Puedes decirme cosas como:

- "Cambia el color principal a azul más oscuro".
- "Añade una sección de certificaciones".

- "Haz la web más elegante para recruiters SAP".
- "Cambia mi teléfono o LinkedIn".

Yo modificaré los archivos necesarios y te diré exactamente qué ha cambiado.
